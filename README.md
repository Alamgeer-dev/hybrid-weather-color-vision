# hybrid-weather-color-vision
# Hybrid Vision & Weather Analysis Semester Project

## 📌 Project Description
This project is a hybrid deep learning and computer vision system designed to detect real-time **weather conditions**, **environment/lighting types**, and **color percentages** from a live camera feed or images.

## 🛠️ Technologies Used
- **PyTorch & MobileNetV2** (For Weather & Environment Classification)
- **OpenCV & K-Means Clustering** (For Color Percentage & Dominant Color Extraction)
- **Vercel** (Frontend Deployment)
- **Python**

## 📂 Model Weights
- The trained model weights file `hybrid_vision_model.pth` is included in the root directory.
